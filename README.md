# The Wizard's Tower

A three-trial fantasy puzzle game for the family (aimed at ~10-year-olds, in English).

1. **Potion Cellar** – water-sort: pour potions until each flask holds one colour (unsolvable boards are rejected by a solver).
2. **Rune Lock** – Lights Out: tap runes to flip them and their neighbours (always solvable; Hint button points at a needed rune).
3. **Riddle Gate** – three riddles answered with letter stones (Hint reveals a letter; keyboard typing works too).

Single self-contained file: `index.html` (no dependencies, works offline, touch-friendly).
